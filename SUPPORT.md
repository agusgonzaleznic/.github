# Support

For a question, a bug or an idea in one of my public repositories, please open an issue in that
repository and pick the matching form. A clear description, and for a problem the steps to
reproduce it, help a lot.

I answer when I have time, and there is no guaranteed response time.

If you found a security problem, please don't open an issue. Report it privately in the
**Security** tab of the repository, as the
[security policy](https://github.com/agusgonzaleznic/.github/blob/main/SECURITY.md) describes.

Thanks for your patience.
